# MIPS Malta Operating System Exercise

In this exercise, you will build a small operating system for the QEMU MIPS Malta board.

## Structure

The exercise is split into multiple steps. Each step can be found in the `steps/` directory.

Every step teaches a new concept and adds a new feature to the operating system.

## Getting Started

1. Fork this repository
2. Complete the steps in order
3. Open a separate merge request for each step

## Submission

For each step:

- Complete the required task
- Answer all questions after the completed task (marked with an info callout).
- Open a merge request containing only the changes for that step
