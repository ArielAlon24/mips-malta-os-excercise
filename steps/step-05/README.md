# Step 05 - Learning about Exceptions and Interrupts

In this step, you will learn how the CPU handles (un)expected events such as exceptions and interrupts.

## General Concepts

> [!NOTE]
> What is an exception?
>
> Describe what an exception is and provide several examples of exceptions that may occur while a program is running.

> [!NOTE]
> What happens inside the CPU when an exception occurs?
>
> Explain:
>
> - How the CPU stops normal execution.
> - How the exception handler address is determined.
> - What processor state must be saved.
> - How execution can later resume.

> [!NOTE]
> What is a hardware interrupt?
>
> How is it different from normal program execution?
>
> Give examples of devices that commonly generate interrupts.

> [!NOTE]
> Why do operating systems prefer interrupts over continuously polling hardware devices?
